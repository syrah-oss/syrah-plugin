Install

Pick your host.

MIT

One plugin named syrah carries the skills and their MCP servers together. Install it once; new work arrives with the next update.

Claude Code

plugin

Marketplace, then plugin.

$ claude plugin marketplace add syrah-oss/syrah-plugin
$ claude plugin install syrah@syrah-plugin

Codex

plugin

Marketplace, then enable it.

$ codex plugin marketplace add syrah-oss/syrah-plugin

Enable in ~/.codex/config.toml, or from the Plugins Directory. 

[plugins."syrah@syrah-plugin"]
enabled = true

OpenCode

skills

Skills directory, from a clone.

# user level
$ for s in "$PWD"/skills/*/; do mkdir -p ~/.config/opencode/skills && ln -sfn "$s" ~/.config/opencode/skills/"$(basename "$s")"; done

Project level works the same way, into .opencode/skills.

Community

Built on the community. Given back to it.

None of this starts from zero. It is built on open specifications, open skills and people who publish their work instead of keeping it internal. We add what our own engagements taught us and put it back out the same way — permissive licence, readable history, no paid tier.

Why we publish

MIT

The tools are only worth anything if they are used. Anything that stands on its own after an engagement is released here rather than left in a private repo.

  • —Same code we run ourselves
  • —Permissive licence, no upsell
  • —Documentation that says what it does not do
